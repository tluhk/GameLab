# Trial runs

Each trial: paste a prompt from `prompts/examples/` (or one built with `tools/build_prompt.py`) into an AI chat, save the reply's code block as `.html`, and run `python3 tools/check_game.py file.html --game <game>`. Then play the game by hand for a few minutes.

Record every run in `results.md` (one row per run). Proposed pass mark: at least 9 of 10 runs per game and language open, play without edits, pass all automatic checks, and contain no outside links.
