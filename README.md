# Mängulabor (Game Lab)

A free web page that helps university students build study games with AI. The student describes a topic, picks one of a few predefined game types, tunes a few options, and gets a ready-to-paste prompt for any AI chat. The AI then writes the game as one self-contained HTML file, which the student can play safely in the browser.

**Status:** planning. There is no code yet; this repository currently holds the plan, requirements and research. Planned hosting is GitHub Pages, and the page will be available in Estonian and English.

## Eesti keeles (mustand)

Mängulabor on tasuta veebileht, mis aitab üliõpilastel luua tehisintellekti abil õppemänge. Üliõpilane kirjeldab teema, valib ette antud mängutüübi ja seaded ning saab valmis juhise (prompti), mille ta kopeerib oma tehisintellekti vestlusesse. Tehisintellekt kirjutab mängu ühe HTML-failina, mida saab brauseris turvaliselt mängida. Leht tehakse eesti ja inglise keeles ning avaldatakse GitHub Pagesis. Praegu on valmis plaan ja nõuded; programmikoodi veel ei ole.

*Eestikeelne tekst on mustand ja vajab emakeelse kõneleja ülevaatust.*
