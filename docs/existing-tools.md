# Existing tools and the gap

Research date: 17 November 2026. The search was mainly in English, so an Estonian tool may exist that was missed. Only the first row below was opened in full; the others are based on search-result summaries and should be treated as unchecked in detail.

## What was found

| Tool | What it does | What is missing for this project |
| --- | --- | --- |
| [AI quiz prompt tool (techmitra.in)](https://techmitra.in/free-ai-quiz-generator-prompt-tool/) | Free form with no login; builds a quiz prompt from board, class, subject, topic, difficulty and question count. It only writes the prompt; the student pastes it into an AI chat. | Quiz formats only; the prompt is in English; curriculum fields are Indian school boards; no learning-science rules; quiz facts must be checked by the user. |
| [Coursebox quiz prompt builder](https://www.coursebox.ai/blog/chatgpt-prompts-for-quiz-writing) | Excel prompt builder plus a checklist for reviewing AI-written quiz questions | Aimed at workplace training; no web form; no games |
| [AI for Education prompt library](https://www.aiforeducation.io/prompts/math-games) | Teacher templates with [BRACKETS] to replace by hand, for example a math-game prompt by grade and topic | Static text; no options; no game catalogue |
| [Educational Game Prompts collection](https://jamesabela.github.io/vibes/systemprompts/index.html) | Ready prompts for single-file HTML games by age group, with technical rules (one file, no libraries, touch-friendly) | Fixed topics; not customisable |
| [Worky Genie quiz game generator](https://www.workybooks.com/create/quiz) | Generates a quiz game inside its own platform from a topic | The platform writes the game, so the student never sees or controls the prompt; language support not checked |
| [YouMind "Edu Interactive Game Generator"](https://youmind.com/skills/educational-game-generator-fUMUXJmXgZ8bbY) | Multi-step prompt that matches the kind of knowledge (facts, procedures) to a game type and checks multimedia-learning principles | Runs on the YouMind platform; not a simple form; Estonian not checked |

## The gap

The closest tools build a prompt from a form, but only for quizzes, and none of those found offers an Estonian interface; only one builds in learning-science checks. None found combines:

- a fixed catalogue of game types, not only quizzes;
- guided options such as levels, difficulty, progress saving and a scoreboard;
- an Estonian and English interface with prompts in the page language;
- study rules grounded in research (see [learning-science.md](learning-science.md));
- a way to run the result safely (see [safety.md](safety.md)).

## Ideas worth borrowing

- The role, task and audience structure of the template libraries.
- The technical rules for single-file games: one HTML file, no libraries, touch-friendly input.
- The idea of matching the kind of knowledge (facts, procedures, relations) to the game type, which the catalogue records through its Bloom-level column.

## Estonian context

AI Leap (TI-Hüpe) launched on 1 September 2025 with grade 10-11 students and their teachers, and was due to widen to vocational schools and new 10th graders in September 2026 (Estonian Ministry of Education and Research announcement).

The announcement names upper-secondary and vocational schools, not universities, so this project assumes nothing about which AI tools university students have. Mängulabor works with any chat AI rather than tying itself to one.
